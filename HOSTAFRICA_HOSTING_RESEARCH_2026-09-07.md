## Web Hosting

HostAfrica describes its general web hosting as DirectAdmin shared hosting. The page advertises free migration, free `.com.ng` domain and SSL, support, daily automatic backups with retention stated as up to 9 days, one-click installers, and Git repository deployment. It describes packages for modest to larger websites and mentions upgradeability. It does not establish a dedicated Node.js process, custom systemd service, root access, or VPS-like isolation.

## LiteSpeed Hosting

HostAfrica describes LiteSpeed shared hosting with DirectAdmin, page/cache acceleration, image optimization, CDN/QUIC options, Redis/Memcached/LSMCD object-cache options, free SSL, backups, and resource-limit tables. The page emphasizes WordPress and CMS integrations, including WooCommerce, and says unlimited traffic is subject to fair-use reduction. It does not establish that a custom Express/tRPC service can run with the process, environment, proxy, database, cron, or websocket controls required by ESUT Marketplace.

## WordPress Hosting

HostAfrica describes a managed WordPress platform with WordPress-focused automation, staging, automatic updates, backups, restore points, malware protection, plugin/theme support, and WordPress-specific support. It is designed around WordPress sites and WordPress administration, not a custom React/Vite plus Node.js/Express/tRPC application.

## Node.js Hosting

HostAfrica describes shared Node.js hosting with Node.js on every plan, SSH available on request, free `.com.ng` domain and SSL, and packages ranging from Starter to Business. The page says Node.js applications can be configured from the hosting control panel and that plans can be upgraded. The page does not establish exact Node.js major versions, memory/CPU/process limits, long-running process behavior, reverse-proxy details, cron authentication, database limits, WebSocket support, environment-variable handling, or production deployment guarantees. Those items require written provider confirmation before purchase.
